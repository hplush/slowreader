# Experiments

Only users with a cloud account send these events to our server. You can turn them off on the _Cloud_ page. An event is only a name, without your user ID, cookies, or IP address.

For events sent once a day, the app keeps the date of the last sending on your device until the next day.

We count how many people see the error page to find and fix the most common problems. These events are sent once a day.

- `fatal-brokenDatabase` the app’s database on the device is broken.
- `fatal-crash` unexpected error broke the app.
- `fatal-noDb` the browser doesn’t allow the app to have a database, for instance, in some private modes.
- `fatal-rejected` the server rejected the app’s changes.
