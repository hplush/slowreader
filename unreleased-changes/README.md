# Unreleased Changes

Each user-visible change adds a file here, and [`scripts/release.sh`](../scripts/release.sh) moves them to [`CHANGELOG.md`](../CHANGELOG.md) and GitHub Release.

- `feature-NAME.md`: `# Title` heading and a short description for users.
- `security-NAME.md`: one sentence, which goes to the `Security & Privacy` list. Add it for every security or privacy improvement, even internal.
- `fix-NAME.md`: one sentence, which goes to the `Fixes` list.
